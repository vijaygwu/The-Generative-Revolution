# Review Rubric

Use this for human review panels when automatic metrics are not enough.

Score each category from `1` to `5`.

| Category | Score | Notes |
|---|---|---|
| Task relevance |  | Does the output actually solve the requested job? |
| Technical quality |  | Is the output visually or functionally plausible? |
| Control fidelity |  | Did the system preserve the requested constraints or edits? |
| Safety / policy |  | Did the output stay within policy and brand boundaries? |
| Release readiness |  | Would you ship this behavior to a real user? |
