# G-CLEDO Scorecard

Use this sheet to compare model families as product choices rather than as
research abstractions.

Ratings:

- `H` = strong fit
- `M` = conditional fit
- `L` = weak fit

| Lens | Rating | Notes |
|---|---|---|
| Goal |  | What user job or system interface is this family best at? |
| Control |  | How easily can it be steered, edited, or conditioned? |
| Latency |  | Does it fit the actual training and serving budget? |
| Data |  | What data quality, consistency, and scale does it need? |
| Eval |  | What minimum evidence proves it is working on the real job? |
| Ops |  | What will make it painful to deploy, monitor, or debug? |
