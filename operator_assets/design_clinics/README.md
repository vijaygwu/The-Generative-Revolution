# Design Clinics

These short memos mirror selected `Generative Design Clinics` from Book 3.

Current scope note: the shipped clinic set covers the reusable Chapter 23-25
workflows only. The Chapter 26 voice-assistant clinic remains book-only in this
release, so use the closest memo here as a template if you want to adapt that
workflow into an internal product brief.

Use them when a team has a real product brief and needs a first defensible
model-family decision rather than a broad survey of options.

Each clinic follows the same fields:

- `brief`
- `best first family`
- `tempting wrong turn`
- `minimum evaluation pack`
- `ship / no-ship call`
- `switch trigger`

Recommended use:

1. Fill out `gcledo_scorecard.md`
2. Pick the closest clinic here and adapt it to the real workflow
3. Run the matching `eval_pack_*.md`
4. Use `ship_no_ship_checklist.md` before launch
5. If the family changes, capture the decision with `modelopsy_template.md`
