# Minimum Viable Evaluation Pack: Anomaly Screening

## Automated Checks

- Threshold stability on reviewed data
- Precision at the actual review budget
- Miss cost by defect subtype
- Drift by acquisition slice

## Human Review

- Top alerts
- Borderline alerts
- Known misses from a held-out reviewed set

## Operational Risk

- Escalation path for severe misses
- Drift policy for sensor or crop changes
- Documented review-volume budget

## Ship Gate

- Stable threshold
- Acceptable reviewer load
- No hidden subgroup collapse

## Common Trap

- Reporting a global discrimination metric while ignoring review burden and calibration
