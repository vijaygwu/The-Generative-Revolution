# Minimum Viable Evaluation Pack: Product Imaging

## Automated Checks

- Alignment proxy on a fixed prompt suite
- Realism proxy on the same suite
- Diversity across seeds
- p95 latency

## Human Review

- Fresh generations
- Edited outputs
- Identity preservation
- Overall usefulness

## Policy and Safety

- Sensitive-category prompt set
- Brand-violation prompt set
- Restricted-content prompt set

## Ship Gate

- No critical failure cluster
- Stable pass rate on the fixed review panel
- Latency within the declared budget

## Common Trap

- Improving alignment while realism, diversity, or editability quietly degrade
